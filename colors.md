# Palette DeskPlan

Reprend la charte **École polytechnique** (bleu X / orange X) et l'étend d'une gamme de surfaces sombres pour le mode nuit des clients.

## Marque

| Nom | Hex | RGB | Usage |
|---|---|---|---|
| Bleu X | `#01426A` | 1, 66, 106 | Couleur primaire, badge, en-têtes |
| Bleu X foncé | `#012E49` | 1, 46, 73 | Aplats, dégradés, surfaces sombres |
| Bleu X clair | `#2E6E96` | 46, 110, 150 | Secondaire, liens en mode sombre |
| Orange X | `#EC6608` | 236, 102, 8 | Accent, boutons d'action, pastille |
| Orange X vif | `#FF7E2E` | 255, 126, 46 | Accent en mode sombre |

## Bleus d'appoint

| Hex | Usage |
|---|---|
| `#6BA4D8` | Bleu secondaire clair |
| `#2E4D8E` | Bleu secondaire moyen |
| `#9DC0DA` | Texte d'accroche sur fond bleu |

## Surfaces sombres (mode nuit)

| Nom | Hex | Usage |
|---|---|---|
| `bg` | `#15181D` | Fond d'application |
| `surface` | `#1E232B` | Cartes |
| `raised` | `#252B34` | Éléments surélevés (survol, sous-panneaux) |

## Typographie

Pile système, sans dépendance de police :
`-apple-system, BlinkMacSystemFont, "Segoe UI", Inter, Roboto, "Helvetica Neue", Arial, sans-serif`.
Le logotype et le monogramme sont en graisse **800 (extra-bold)**, interlettrage resserré.
